## Die Ableitungsregeln

Mit der Ableitung als Grenzwert kannst du jede Steigung bestimmen. Für Polynome geht das mit ==wenigen Regeln== viel schneller.

::merkkarte{#potenzregel title="Potenzregel"}
Für $f(x) = x^n$ gilt $f'(x) = n x^(n-1)$. Der Exponent wird ==zum Faktor== und ==verringert sich um 1==.

::beispiel
$f(x) = x^3 => f'(x) = 3x^2$

$f(x) = x^7 => f'(x) = 7x^6$

::merkkarte{#faktorregel title="Faktorregel"}
Für $f(x) = c dot g(x)$ gilt $f'(x) = c dot g'(x)$. Ein konstanter Faktor ==bleibt beim Ableiten stehen==.

::beispiel
$f(x) = 5x^2 => f'(x) = 5 dot 2x = 10x$

## Mehrere Regeln nacheinander

Bei einem Term wie $f(x) = 4x^3$ wendest du zuerst die Faktorregel und dann die Potenzregel an:

$ f'(x) = 4 dot 3x^2 = 12x^2 $
