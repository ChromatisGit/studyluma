## Merkkarte: "Testregel Eins"

Eine künstliche Regel lautet:

$f(x) = 3 x^2$

::beispiel

Für $x = 2$ erhält man $12$.

::beispiel

Für $x = 0$ erhält man $0$.

---

Nach dem expliziten Ende der Merkkarte folgt wieder normaler Fließtext.

## Merkkarte: "Testregel Zwei"

## "Umformungen und Beispiele"

Auf beiden Seiten machen wir dasselbe.

::beispiel
$0,5 x + 2 = x + 1,5 | *2$
$0,5 x*2 + 2*2 = x*2 + 1,5*2$
$x + 4 = 2x + 3$

$|x + 3| = 5 | -5$
$|x + 3| - 5 = 0$

::beispiel
Ein zweites Beispiel mit $P(2 | 5)$ im Text.
