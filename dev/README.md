# Development instance

`studyluma-dev` is the private instance for developing StudyLuma. It consumes the packages through `workspace:*` and is never distributed. It holds only:

- `config/app.toml` — deployment (target, domain `dev.studyluma.localhost`);
- `config/catalog.toml` — content root and the published courses (`ui-test`, `randfaelle`);
- `config/classroom.toml` — the classroom defaults, written out;
- `content/` — test content, edge cases and UI fixtures (author syntax: see the compiler README);
- `src/worker.workerd.test.ts` — builds the Cloudflare Worker and boots it in workerd;
- `package.json` and the one-line `tsconfig.json` / `eslint.config.js` stubs.

Routes, root, server hook, build configuration and tooling are generated by Chromatis under `.chromatis/` from the app's manifest.

```sh
bun run check      # config, content compiles to a valid catalog, typecheck, lint, format, tests
bun run build
bun run dev        # http://localhost:5173
bun run inspect
```

Install first from the workspace root `/home/ch/dev/studyluma-planning` (`bun install`).
